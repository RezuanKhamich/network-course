# Связь вопросов с уроками по сетям

Источник истины — `lessonId` у вопроса в `web/courses/network/content.js`. Движок использует его в разборе теста, экзамена и повторения. Самопроверки связаны со своим уроком. Таблица ниже перечисляет 162 вопроса модульных тестов; вместе с 126 самопроверками банк содержит 288 вопросов.

Эта карта показывает основное место для повторения. Для межтематических заданий нужны также предыдущие уроки соответствующего модуля. Автоматическая проверка существования ссылки не доказывает смысловую полноту теории.
