# Курсы для разработчиков

Бесплатные интерактивные курсы на русском языке: короткая теория, схемы, интерактивные виджеты, самопроверка после каждого урока, тесты модулей и финальный экзамен. Прогресс, опыт и достижения хранятся только у вас в браузере, при желании — в JSON-файле на диске.

**Сайт:** https://rezuankhamich.github.io/network-course/

| Курс | Модулей | Уроков | Темы |
|---|---|---|---|
| 🌐 [Сети для разработчиков](courses/network/) | 13 | 63 | модели OSI/TCP-IP, Ethernet, IPv4/IPv6, маршрутизация, TCP/UDP, DNS, HTTP, TLS, CDN, диагностика |
| 🤖 [AI-агенты для разработчиков](courses/ai-agents/) | 13 | 59 | токены и сэмплинг, промптинг, RAG, tool use, MCP, память, архитектуры агентов, оценка, безопасность |

## Возможности

- **Общий интерфейс.** Главная страница с каталогом курсов, кнопкой «Продолжить» с места, где вы остановились, и сводкой прогресса по всем курсам.
- **Прогресс.** Уроки, лучшие результаты тестов, работа над ошибками, финальный экзамен. Модули открываются по очереди после сдачи теста (блокировку можно отключить).
- **Опыт и уровни.** XP за уроки, верные ответы в самопроверке, сданные тесты, экзамены и достижения. Уровни с рангами от «Новичка» до «Гуру».
- **Удержание.** Серия дней подряд с предупреждением, когда она под угрозой; дневная цель по XP (20/50/100/200) с индикатором в шапке; три задания на день; карта активности за 20 недель.
- **Достижения.** 33 штуки трёх уровней (бронза, серебро, золото), включая секретные. На странице профиля видно, сколько осталось до каждого.
- **Аккаунт.** Регистрация по email с подтверждением, вход, восстановление и смена пароля, удаление аккаунта. После входа прогресс синхронизируется между устройствами; без входа всё работает как раньше.
- **Данные.** Автосохранение в файл через File System Access API (Chrome, Edge, Opera, Яндекс Браузер), ручной экспорт/импорт, слияние двух файлов, синхронизация между вкладками. Файлы прогресса из старых одностраничных версий курсов импортируются автоматически.
- Светлая и тёмная темы, адаптивная вёрстка, без сборки и зависимостей.

## Структура

```
web/                         фронтенд на Vite (многостраничная сборка)
  index.html                 главная: каталог, профиль и достижения, данные и настройки
  assets/
    css/base.css             общие стили и палитра по умолчанию
    css/game.css             плашка игрока, достижения, карта активности, каталог
    js/storage.js            единое хранилище прогресса всех курсов, файл, импорт/слияние, утилиты
    js/courses.js            реестр курсов для каталога
    js/game.js               XP, уровни, серии, дневная цель, достижения, конфетти
    js/engine.js             движок страницы курса: навигация, уроки, тесты, экзамен, глоссарий
    js/hub.js                логика главной страницы
  courses/<id>/
    index.html               страница курса
    main.js                  точка входа: передаёт контент и course.js в startCourse()
    theme.css                цвета курса (переопределяют токены base.css)
    content.js               модули, уроки, вопросы, глоссарий
    course.js                настройки курса (COURSE), виджеты, сквозной сценарий, инструменты, шпаргалки
  public/                    файлы, которые копируются в сборку как есть
  scripts/validate-cyber.js  проверка контента курса ИБ
docs/                        программы курсов и промты для генерации контента
```

Код разбит на ES-модули: каждый файл явно импортирует то, чем пользуется, а Vite собирает для каждой страницы свой бандл с хешами в именах файлов, так что после обновления браузер не возьмёт старую версию из кеша. Маршрутизация внутри страниц — через `#`-хеш, поэтому серверу достаточно отдавать статические файлы.

Все страницы лежат на одном origin, поэтому прогресс общий: курс пишет в тот же ключ `localStorage`, который читает главная.

## Запуск локально

Нужен Node.js 20+.

```bash
cd web
npm install
npm run dev
```

Откроется http://localhost:5173 с горячей перезагрузкой.

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер |
| `npm run build` | сборка в `web/dist/` |
| `npm run preview` | локальный просмотр собранной версии |
| `npm run lint` | ESLint: неопределённые и неиспользуемые имена |
| `npm run validate` | проверка контента курса ИБ |
| `npm run check` | всё сразу: lint, validate, build |

### Сервер (аккаунты и синхронизация прогресса)

Нужен Docker для локальной базы PostgreSQL.

```bash
docker compose up -d db
cd server
cp .env.example .env
npm install
npm run migrate
npm run dev
```

API поднимется на http://127.0.0.1:3000, а dev-сервер Vite проксирует к нему `/api`. Без `SMTP_URL` письма (подтверждение регистрации, сброс пароля) выводятся в консоль сервера. Тесты гоняются на отдельной базе `devcourses_test`: `npm test`.

## Публикация

`npm run build` складывает готовый сайт в `web/dist/` — это обычная статика, её может отдавать любой веб-сервер (nginx, хостинг). Если сайт живёт не в корне домена, укажите путь при сборке: `VITE_BASE=/путь/ npm run build`.

## Как добавить курс

1. Скопируйте папку `web/courses/network/` в `web/courses/<новый-id>/` — Vite подхватит её как новую страницу автоматически.
2. В `course.js` поменяйте объект `COURSE` (id, название, описание, иконку) и виджеты/сценарий/шпаргалки.
3. В `content.js` опишите `MODULES`, `UPCOMING` и `GLOSSARY` в том же формате. Типы вопросов: `single`, `multiple`, `order`, `match`, `input`, `analyze`.
4. В `theme.css` задайте цвета.
5. Добавьте запись в `web/assets/js/courses.js` — курс появится в каталоге.
6. Запустите `npm run check`.

При желании добавьте достижение за курс в `ACHIEVEMENTS` в `web/assets/js/game.js`.

## Формат прогресса

Прогресс хранится в `localStorage` под ключом `dev-courses-progress` и в файле `dev-courses-progress.json`:

```json
{
  "app": "dev-courses", "version": 2, "savedAt": "…",
  "settings": { "theme": "system", "dailyGoal": 50, "effects": true },
  "profile": { "name": "", "avatar": "🦉", "createdAt": "…" },
  "game": { "awarded": {}, "days": {}, "achievements": {}, "flags": {} },
  "courses": { "network": { "lessons": {}, "tests": {}, "finalExam": null, "checks": {}, "unlockAll": false } },
  "last": { "course": "network", "hash": "#/l/7-2", "title": "…" }
}
```

XP начисляется по уникальным ключам (`network:l:0-1`, `network:t:m3` и т. п.), поэтому повторные действия, импорт и слияние файлов не дают опыт дважды.
