## Возможности

- **Общий интерфейс.** Главная страница с каталогом курсов, кнопкой «Продолжить» с места, где вы остановились, и сводкой прогресса по всем курсам.
- **Прогресс.** Уроки, лучшие результаты тестов, работа над ошибками, финальный экзамен. Модули открываются по очереди после сдачи теста (блокировку можно отключить).
- **Опыт и уровни.** XP за уроки, верные ответы в самопроверке, сданные тесты, экзамены и достижения. Уровни с рангами от «Новичка» до «Гуру».
- **Удержание.** Серия дней подряд с предупреждением, когда она под угрозой; дневная цель по XP (20/50/100/200) с индикатором в шапке; три задания на день; карта активности за 20 недель.
- **Достижения.** 36 штук трёх уровней (бронза, серебро, золото), включая секретные. На странице профиля видно, сколько осталось до каждого.
- **Данные.** Автосохранение в файл через File System Access API (Chrome, Edge, Opera, Яндекс Браузер), ручной экспорт/импорт, слияние двух файлов, синхронизация между вкладками. Файлы прогресса из старых одностраничных версий курсов импортируются автоматически.
- Светлая и тёмная темы, адаптивная вёрстка, без сборки и зависимостей.

## Структура

```
index.html                 главная: каталог, профиль и достижения, данные и настройки
ai-agents-course.html      редирект со старого адреса курса AI-агентов
assets/
  css/base.css             общие стили и палитра по умолчанию
  css/game.css             плашка игрока, достижения, карта активности, каталог
  js/storage.js            единое хранилище прогресса всех курсов, файл, импорт/слияние, утилиты
  js/courses.js            реестр курсов для каталога
  js/game.js               XP, уровни, серии, дневная цель, достижения, конфетти
  js/engine.js             движок страницы курса: навигация, уроки, тесты, экзамен, глоссарий
  js/hub.js                логика главной страницы
courses/<id>/
  index.html               страница курса: подключает общие файлы и файлы курса
  theme.css                цвета курса (переопределяют токены base.css)
  content.js               модули, уроки, вопросы, глоссарий
  course.js                настройки курса (COURSE), виджеты, сквозной сценарий, инструменты, шпаргалки
```

Скрипты подключаются обычными тегами `<script>` в фиксированном порядке (`storage → courses → game → content → course → engine`), поэтому сайт работает без сборщика — и на GitHub Pages, и при открытии `index.html` прямо с диска. Маршрутизация внутри страниц — через `#`-хеш, так что серверные перенаправления не нужны.

Все страницы лежат на одном origin, поэтому прогресс общий: курс пишет в тот же ключ `localStorage`, который читает главная.

## Запуск локально

Подойдёт любой статический сервер из корня репозитория:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000. Можно и просто открыть `index.html` в браузере, но автосохранение в файл и общий прогресс между страницами надёжнее работают через сервер.

## Публикация на GitHub Pages

1. Запушьте репозиторий на GitHub.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `master`, папка `/ (root)`.
3. Через минуту сайт появится по адресу `https://<user>.github.io/<repo>/`.

Файл `.nojekyll` отключает обработку Jekyll, чтобы GitHub Pages отдавал файлы как есть. Все ссылки относительные, поэтому сайт работает и из подпапки репозитория, и на собственном домене.

## Как добавить курс

1. Скопируйте папку `courses/network/` в `courses/<новый-id>/`.
2. В `course.js` поменяйте объект `COURSE` (id, название, описание, иконку) и виджеты/сценарий/шпаргалки.
3. В `content.js` опишите `MODULES`, `UPCOMING` и `GLOSSARY` в том же формате. Типы вопросов: `single`, `multiple`, `order`, `match`, `input`, `analyze`.
4. В `theme.css` задайте цвета.
5. Добавьте запись в `assets/js/courses.js` — курс появится в каталоге.

При желании добавьте достижение за курс в `ACHIEVEMENTS` в `assets/js/game.js`.

## Формат прогресса

Прогресс хранится в `localStorage` под ключом `dev-courses-progress` и в файле `dev-courses-progress.json`:

```json
{
  "app": "dev-courses", "version": 2, "savedAt": "…",
  "settings": { "theme": "system", "dailyGoal": 50, "effects": true },
  "profile": { "name": "", "avatar": "🦉", "createdAt": "…" },
  "game": { "awarded": {}, "days": {}, "achievements": {}, "flags": {} },
  "courses": { "network": { "lessons": {}, "tests": {}, "finalExam": null, "checks": {}, "unlockAll": false } },
  "last": { "course": "network", "hash": "#/l/7-2", "title": "…" }
}
```

XP начисляется по уникальным ключам (`network:l:0-1`, `network:t:m3` и т. п.), поэтому повторные действия, импорт и слияние файлов не дают опыт дважды.
